# 关于我

你好，我是 **HY**，目前就读于东南大学网络空间安全学院，是一名硕士研究生，主要关注 **AI Agent 与大模型应用工程**。

## 研究与关注方向

我对 Agent 系统背后的工程机制尤其感兴趣，当前主要关注：

- Agent Architecture 与 Agent Loop
- 工具调用（Tool Use）与 MCP
- Context Engineering
- Memory 与长期记忆机制
- RAG（Retrieval-Augmented Generation）
- 权限控制、错误处理与可观测性等 Harness Engineering 问题

## 当前的学习与实践

相比单纯调用大模型 API，我更希望理解一个真正可用的 Agent 系统是如何从底层被设计和构建出来的。

目前，我正在通过 **Claude Code、Codex、Pi、OpenCode** 等主流 Agent 项目持续学习和实践，分析它们在上下文管理、工具编排、记忆机制、权限边界和运行时控制等方面的设计，并尝试将这些理解沉淀为项目、技术文章和系统化笔记。
